**src/instrumentation.ts (new file):**

Create the Next.js instrumentation hook. This file is a Next.js convention — it runs once when the server starts (Next.js 13.4+).

```typescript
export async function register() {
  // Only run in Node.js runtime (not Edge)
  if (process.env.NEXT_RUNTIME === 'nodejs') {
    const { initPublisherRegistry } = await import('@/lib/publishing/publisher-registry');
    const { initAdapterRegistry } = await import('@/lib/research/adapter-registry');
    await initPublisherRegistry();
    await initAdapterRegistry();
  }
}
```

Use dynamic `import()` inside the function body to avoid importing server-only modules at the top level (which would fail in Edge runtime context). The `NEXT_RUNTIME` check ensures this only runs in the Node.js server process.

NOTE: Next.js must have `experimental.instrumentationHook` enabled in `next.config.js` (or `next.config.ts`). Check if this config exists and add the flag if needed. In Next.js 15+, instrumentation is stable and may not need the experimental flag. Read `next.config.*` to determine the correct approach.
