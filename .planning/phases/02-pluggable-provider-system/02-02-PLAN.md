**publisher-registry.ts:**
Create the publisher registry singleton:

1. Import `Registry` from `@/lib/providers/registry` and `PublisherProvider`, `PROVIDER_API_VERSION` from `@/lib/providers/types`.
2. Create an `isPublisherProvider(val: unknown): val is PublisherProvider` duck-type guard function that checks:
   - typeof val === 'object' && val !== null
   - name is string, platform is string, displayName is string
   - publish is function, formatDraft is function
   - apiVersion === PROVIDER_API_VERSION
   - configSchema is Array
3. Export `publisherRegistry` — a `new Registry<PublisherProvider>(p => p.platform)`.
4. Export `initPublisherRegistry(): Promise<void>` — calls `publisherRegistry.loadDirectory()` with:
   - dir: `path.resolve(__dirname, 'providers')` (use `import.meta.url` + `fileURLToPath` + `path.dirname` for ESM-compatible resolution, OR use `__dirname` if the project's tsconfig supports it — check tsconfig for module resolution)
   - suffix: `.provider.ts` (accept `.provider.js` too for production builds — use a suffix check that accepts either)
   - validate: wraps `isPublisherProvider` — `(mod) => isPublisherProvider(mod) ? mod : null`

NOTE on path resolution: The project uses `"module": "esnext"` in tsconfig but runs via `tsx` in dev. Use `path.resolve(process.cwd(), 'src/lib/publishing/providers')` as the directory path — this is the pattern recommended by research and works in both tsx and Next.js contexts.

**queue-runner.ts updates:**
1. Remove the two direct imports: `publishToSubstack` from `./substack` and `publishToLinkedIn` from `./linkedin`.
2. Add import: `import { publisherRegistry } from '@/lib/publishing/publisher-registry'`.
3. Replace the if/else dispatch block (lines ~86-92) with:
   ```typescript
   const provider = publisherRegistry.get(item.channel.platform);
   if (!provider) {
     throw new Error(`No publisher registered for platform '${item.channel.platform}'`);
   }
   platformResponse = await provider.publish(item.draft, item.channel);
   ```
4. Keep ALL other logic unchanged — retry, error handling, stuck recovery, etc.

3. For the "unknown platform" test case: mock `publisherRegistry.get()` to return undefined.
4. Keep all existing test scenarios — just change the mock targets from direct publisher imports to registry lookups.
