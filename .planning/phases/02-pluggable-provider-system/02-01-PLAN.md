<task type="auto">
  <name>Task 2: Implement generic Registry class with tests</name>
  <files>src/lib/providers/registry.ts, tests/lib/providers/registry.test.ts</files>
  <action>
Create `src/lib/providers/registry.ts`:

A generic `Registry<T>` class that handles provider discovery, validation, and registration. Constructor takes a `keyExtractor: (provider: T) => string` function so the same class works for both publisher (key = platform) and adapter (key = id) registries.

Required behavior:
- `loadDirectory(dir: string, suffix: string, validate: (mod: unknown) => T | null): Promise<void>` — scans `dir` with `fs.readdirSync`, filters files ending with `suffix`, dynamically imports each via `import()` with `path.resolve()`, calls `validate()` on the default export (fall back to module itself if no default), registers valid providers, logs `console.warn` with file name and reason for invalid ones. After scanning, sets `frozen = true`.
- `register(provider: T): void` — registers a single provider by key. Throws if already frozen. Useful for tests.
- `get(key: string): T | undefined` — returns provider by key.
- `getAll(): T[]` — returns all registered providers.
- `has(key: string): boolean` — checks if key is registered.
- `keys(): string[]` — returns all registered keys.
- After `loadDirectory()` completes, the registry is frozen. Calls to `register()` after freeze throw an error.

Use `fs` and `path` from Node builtins. Use dynamic `import()` (NOT `require()`).

Import `PROVIDER_API_VERSION` from `./types` — but do NOT enforce version checking inside the Registry class itself. Version checking is the validator function's responsibility (passed by the caller). The Registry is generic and does not know about PROVIDER_API_VERSION.

Create `tests/lib/providers/registry.test.ts`:

Unit tests for Registry<T> using Vitest:
1. `register()` adds a provider retrievable by `get()`
2. `getAll()` returns all registered providers
3. `has()` returns true for registered, false for unregistered keys
4. `keys()` returns all registered key strings
5. `register()` throws after registry is frozen
6. `loadDirectory()` with mock directory — use `vi.mock('fs')` to mock `readdirSync`, and `vi.mock()` or `vi.spyOn` for dynamic import. Verify valid providers are registered and invalid ones are skipped with console.warn.
7. `loadDirectory()` freezes the registry

Test the generic behavior — use a simple test type like `{ id: string; apiVersion: number }` for T.
