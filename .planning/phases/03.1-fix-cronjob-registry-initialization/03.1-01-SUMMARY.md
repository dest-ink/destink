## Decisions Made
- Shared bootstrap module is single entry point for all process types — avoids future drift if registry init logic changes
- Registry.loadDirectory() sequential calls safe: the function writes via Map.set (idempotent) and sets frozen=true at end; second call overwrites frozen to true (no error, no duplication)
- Job scripts log registry count after init to aid operational debugging of CronJob runs
