Replace the stub in `src/app/(app)/audit/page.tsx` with a server component that:

1. Add `export const dynamic = 'force-dynamic';` at the top (same as channels/[id]/page.tsx).

2. Fetch three datasets using Drizzle groupBy queries:

   **Summary totals (no groupBy):**
   ```typescript
   const [summary] = await db
     .select({
       totalCost: sql<string>`coalesce(sum(${aiAuditLog.costUsd}), '0')`,
       totalTokens: sql<number>`coalesce(sum(${aiAuditLog.promptTokens} + ${aiAuditLog.completionTokens}), 0)`,
       callCount: sql<number>`cast(count(*) as int)`,
     })
     .from(aiAuditLog);
   ```

   **By channel (with channel name join):**
   ```typescript
   const byChannel = await db
     .select({
       channelId: aiAuditLog.channelId,
       channelName: channels.name,
       totalCost: sql<string>`coalesce(sum(${aiAuditLog.costUsd}), '0')`,
       totalTokens: sql<number>`coalesce(sum(${aiAuditLog.promptTokens} + ${aiAuditLog.completionTokens}), 0)`,
       callCount: sql<number>`cast(count(*) as int)`,
     })
     .from(aiAuditLog)
     .leftJoin(channels, eq(aiAuditLog.channelId, channels.id))
     .groupBy(aiAuditLog.channelId, channels.name)
     .orderBy(sql`sum(${aiAuditLog.costUsd}) desc nulls last`);
   ```

   **By operation:**
   ```typescript
   const byOperation = await db
     .select({
       operation: aiAuditLog.operation,
       totalCost: sql<string>`coalesce(sum(${aiAuditLog.costUsd}), '0')`,
       totalTokens: sql<number>`coalesce(sum(${aiAuditLog.promptTokens} + ${aiAuditLog.completionTokens}), 0)`,
       callCount: sql<number>`cast(count(*) as int)`,
     })
     .from(aiAuditLog)
     .groupBy(aiAuditLog.operation)
     .orderBy(sql`sum(${aiAuditLog.costUsd}) desc nulls last`);
   ```

3. Parse results: `parseFloat()` for cost strings, `Number()` for token/count values.

4. Render the page layout:

   ```tsx
   <div className="p-6 max-w-5xl mx-auto">

     <AuditSummaryCards summary={parsedSummary} />
     <AuditTabs byChannel={parsedByChannel} byOperation={parsedByOperation} />
   </div>
   ```

5. Update `loading.tsx` to show a skeleton matching the layout (three skeleton cards at top, skeleton table below). Use the established pattern from other loading.tsx files in the project.

IMPORTANT: costUsd is a Postgres `numeric` column — Drizzle returns it as a string. MUST parseFloat() before passing to components. This is the established pattern from channels/[id]/page.tsx.

IMPORTANT: Some aiAuditLog rows have `channelId = null` (system-level AI calls). The leftJoin will produce null channelName for these. Pass them through — the AuditTabs component will display "Unattributed" for null channel names.
