<task type="auto" tdd="true">
  <name>Task 2: Batch draft generation engine + tests</name>
  <files>src/lib/generation/batch.ts, tests/lib/generation/batch.test.ts</files>
  <behavior>
    - assignContentTypes(topics, count, shortFormPercent) returns array of {topic, contentType}
    - Topics sorted by relevanceScore descending, sliced to count
    - 70% of 3 = 2 notes + 1 article
    - 50% of 3 = 2 notes + 1 article (Math.round favors short-form on ties)
    - 100% of 3 = 3 notes, 0 articles
    - 0% of 3 = 0 notes, 3 articles
    - generateDraftsForRun() creates drafts for a single channel from run topics
    - Skips topics with titles matching existing drafts for that channel (case-insensitive)
    - Adds newly generated titles to dedup set to prevent intra-batch dupes
    - Each draft inserted with status: 'pending_review', researchRunId set
    - draftsGenerated updated on researchRuns after batch completes
    - Partial failures: continues generating remaining drafts, returns failedCount
    - onProgress callback receives draft-start, draft-complete, draft-error, draft-skipped events
  </behavior>
  <action>
    Create `src/lib/generation/batch.ts`:

    1. Export `assignContentTypes(topics: TopicRecommendation[], count: number, shortFormPercent: number)`:
       - Sort topics copy by relevanceScore descending, slice to `count`
       - Calculate `noteCount = Math.round((shortFormPercent / 100) * sorted.length)`
       - Map: index < noteCount gets 'note', else 'article'
       - Return `Array<{ topic: TopicRecommendation; contentType: 'note' | 'article' }>`

    2. Export `DraftBatchResult` interface with `generatedIds: string[]` and `failedCount: number`.

    3. Export `generateDraftsForRun(runId, channelId, topics, maxDraftsPerRun, shortFormPercent, onProgress?)`:
       - Load channel from DB for personaPrompt
       - Load recent draft titles for this channel from DB (limit 10, desc by createdAt)
       - Build `existingTitles` Set from recent titles (lowercase)
       - Call `assignContentTypes()` for the batch
       - Loop through assignments:
         a. If `existingTitles.has(topic.title.toLowerCase())`, emit draft-skipped, continue
         b. Emit draft-start event
         c. Generate draftId with `randomUUID()`
         d. Call `generateDraft()` from generator.ts
         e. Insert draft into DB with:
            - `id: draftId`, `channelId`, `researchRunId: runId`, `contentType`
            - `title: generated.headlineOptions[0] ?? null`
            - `status: 'pending_review'` (per DRAFT-06 -- explicit, not relying on default)
            - All other generated fields
         f. Push draftId to generatedIds
         g. Add topic.title.toLowerCase() to existingTitles (prevent intra-batch dupes)
         h. Emit draft-complete event
         i. On error: increment failedCount, emit draft-error, continue loop
       - After loop, if generatedIds.length > 0, update `researchRuns.draftsGenerated` with the IDs
       - Return `{ generatedIds, failedCount }`

    4. The onProgress callback type should be `OnProgress` (reuse from progress.ts).

    Create `tests/lib/generation/batch.test.ts`:
    - Test `assignContentTypes()` pure function with multiple scenarios:
      - 70% of 3 topics: expect 2 notes, 1 article
      - 50% of 3 topics: expect 2 notes, 1 article (tie favors short-form)
      - 50% of 4 topics: expect 2 notes, 2 articles
      - 100% of 3: expect 3 notes, 0 articles
      - 0% of 3: expect 0 notes, 3 articles
      - Topics sorted by relevanceScore: highest-scored topics get note (first N slots)
      - count > topics.length: only returns topics.length items
    - These tests are unit tests for the pure function; no mocking needed.
  </action>
