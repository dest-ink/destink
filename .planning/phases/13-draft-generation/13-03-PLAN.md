    Client component ('use client') that handles the Generate Drafts button and "Drafts Generated" badge.

    Props:
    ```typescript
    interface GenerateDraftsButtonProps {
      runId: string;
      researcherId: string;
      initialDraftsGenerated: string[] | null;
    }
    ```

    State:
    - `draftsGenerated`: string[] | null -- initialized from `initialDraftsGenerated`
    - `running`: boolean -- whether SSE stream is active
    - `lines`: LogLine[] -- same log line pattern as ResearchRunPanel
    - `logRef`: ref for auto-scroll

    Behavior:
    - If `draftsGenerated` has items (length > 0), render:
      ```tsx
      <div className="flex items-center gap-2">
        <Badge variant="outline" className="text-green-600 border-green-500/20 bg-green-500/10">
          Drafts Generated ({draftsGenerated.length})
        </Badge>
        <Link href="/drafts" className="text-xs text-primary hover:underline">
          View drafts
        </Link>
      </div>
      ```
    - If no drafts, render a "Generate Drafts" button (disabled when `running`)
    - On click, POST to `/api/researchers/${researcherId}/runs/${runId}/generate-drafts`
    - Read SSE stream with the same pattern as ResearchRunPanel:
      - Decoder, buffer, split on `\n\n`, parse `data: ` prefix
      - Handle draft events: draft-start (blue), draft-complete (green), draft-error (red), draft-skipped (muted), drafts-done (green/yellow)
    - After stream closes (`reader.read()` returns `done: true`):
      - Set `running = false`
      - If any drafts-done event was received, update `draftsGenerated` state from the event's `draftIds`
      - Call `router.refresh()` to re-fetch server component data (Pitfall 4 from RESEARCH.md)
    - Show log lines below the button when `lines.length > 0`, using same styling as ResearchRunPanel (font-mono, text-xs, border rounded-lg, max-h-60 overflow-y-auto)
    - Handle non-ok response: if 409, show "Drafts already generated" in the log. For other errors, show the error message.

    Imports: `useState`, `useRef`, `useEffect` from react, `useRouter` from next/navigation, `Link` from next/link, `Badge` from ui/badge, `Button` from ui/button, `ResearchProgressEvent` type from progress.
