    **1. Wire auto-draft into `runResearchForResearcher()` in `src/lib/research/engine.ts`:**

    Add import at the top:
    ```typescript
    import { generateDraftsForRun } from '@/lib/generation/batch';
    ```

    After the `run-complete` event emission (line ~198-203) and the console.log, INSIDE the for-loop body for each channel, add the auto-draft hook:

    ```typescript
    // Auto-draft: generate drafts if enabled on this researcher
    if (researcher.autoDraft) {
      try {
        const topics = run.topicsFound as TopicRecommendation[] ?? [];
        const result = await generateDraftsForRun(
          run.id,
          channel.id,
          topics,
          researcher.maxDraftsPerRun,
          researcher.shortFormPercent,
          onProgress,
        );
        onProgress?.({
          type: 'drafts-done',
          generated: result.generatedIds.length,
          failed: result.failedCount,
          draftIds: result.generatedIds,
        });
      } catch (err) {
        // Draft generation failures do NOT affect research run status
        onProgress?.({
          type: 'run-error',
          error: `Draft generation failed: ${err instanceof Error ? err.message : String(err)}`,
        });
      }
    }
    ```

    IMPORTANT: The auto-draft hook is INSIDE the per-channel loop. Each channel's run gets its own draft generation call. This ensures `draftsGenerated` is set per-run correctly (see Pitfall 2 from RESEARCH.md).
