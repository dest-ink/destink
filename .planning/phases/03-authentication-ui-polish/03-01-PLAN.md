```typescript
export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  email: text('email').notNull().unique(),

4. Create `src/auth.ts` — full Auth.js config:
- Import and spread `authConfig`
- Add `session: { strategy: 'jwt', maxAge: 30 * 24 * 60 * 60 }` (30 days)
- Add Credentials provider with `authorize` callback:
  - Validate with zod: `email` (string.email), `password` (string.min(8))
  - Query `users` table with Drizzle `eq(users.email, email)`
  - Compare password with `bcrypt.compare(password, user.passwordHash)`
  - Return `{ id: user.id, email: user.email }` on success, `null` on failure
- Export `{ handlers, signIn, signOut, auth }` from `NextAuth(config)`

```
IMPORTANT: Use `proxy.ts` with `export { auth as proxy }` — NOT `middleware.ts`. This is Next.js 16.

Wrap EVERY existing API route handler with `auth()` from `@/auth`. This is formulaic — the same pattern applied to all 11 files.

Pattern for each route file:
```typescript
import { auth } from '@/auth';
import { NextResponse } from 'next/server';

export const GET = auth(function GET(req) {
  if (!req.auth) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  // ... existing handler body (keep all existing logic intact)
});
```

Apply this pattern to ALL route handlers in these files:
- `src/app/api/channels/route.ts` (GET, POST)
- `src/app/api/channels/[id]/route.ts` (GET, PUT, DELETE)
- `src/app/api/drafts/route.ts` (GET, POST)
- `src/app/api/drafts/[id]/approve/route.ts` (POST/PUT)
- `src/app/api/drafts/[id]/reject/route.ts` (POST/PUT)
- `src/app/api/queue/route.ts` (GET, POST)
- `src/app/api/queue/[id]/route.ts` (GET, DELETE)
- `src/app/api/queue/[id]/publish-now/route.ts` (POST)
- `src/app/api/queue/[id]/retry/route.ts` (POST)
- `src/app/api/research/route.ts` (POST)
- `src/app/api/voice/route.ts` (POST)

IMPORTANT: Keep ALL existing handler logic. Only add the `auth()` wrapper and the `if (!req.auth)` guard at the top. The `auth()` function from Auth.js v5 wraps route handlers — the `req` parameter gains a `.auth` property.

Note: The `req` type changes from `NextRequest` to Auth.js's extended request. If TypeScript complains, use `import type { Session } from 'next-auth'` and type the handler parameter accordingly, or use the `auth()` wrapper which automatically types `req`.
